# JB Blog - Julien Bechkri's Professional Platform

Plateforme de présentation et blog de Julien Bechkri - Digital Transformation & Organisation, Head of Product Management, Direction de projet IT.

## 🚀 Quick Start

```bash
# Installation des dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Build pour production
npm run build

# Preview du build
npm run preview
```

## 📁 Structure du Projet

```
src/
├── layouts/       # Templates réutilisables
├── components/    # Composants Astro
├── pages/         # Routes du site
├── content/       # Articles et projets en Markdown
├── styles/        # Styles globaux
└── utils/         # Utilitaires
```

## 🎨 Stack Technologique

- **Astro** - Framework statique
- **Tailwind CSS** - Utility-first CSS
- **TypeScript** - Type safety
- **React** (light) - Composants interactifs (optionnel)

## 📝 Pages Principales

- **/** - Accueil
- **/about** - À propos
- **/projects** - Mes projets
- **/blog** - Articles
